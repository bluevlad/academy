## AI 기반 1:1 문의 라우팅 (확장 명세)

```
학생이 1:1 문의 등록
       │
   ┌───┴────────────────┐
   │ AI 카테고리 분류 모델 │
   └───┬────────────────┘
       ├ 수강·강의 내용    → 담당 강사 메일 + 운영자 cc
       ├ 결제·환불        → 운영자 (결제담당) 메일
       ├ 기술·로그인      → 시스템관리자 메일
       └ 기타·분류불가    → 운영자 일괄 큐
                         │
                         ▼
                담당자 콘솔에서 답변 등록
                         │
                         ▼
                학생에게 답변 알림 (사이트 + 이메일)
```

- 분류 기준·담당자 매핑은 시스템관리자 `/system/ai-routing` 에서 설정
- 분류 모델: 초기 룰베이스(키워드) → 점진적으로 LLM 기반
- 수동 재배정 가능 (운영자가 담당자 변경)

4. **AI 라우팅 초기 버전** — 룰베이스로 시작(키워드 매칭) / 바로 LLM 연동?
5. **이벤트·배너** — 운영자 등록 / 시스템관리자 승인 분리?

- 현행: `/api/**` (`/api/auth/**`, `/api/user/**` 제외) — 모두 `hasRole("ADMIN")`
- 마이그레이션:
