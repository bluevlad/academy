## 검토 필요 (사용자 의견 요청)

1. **그룹 명칭** — "운영" / "회원" / "강의·콘텐츠" 같은 분류명 학원 표준에 맞는지?
2. **수강관리 vs 주문관리** — "수강(주문)관리" 라는 현재 라벨이 모호. 분리할지 통합할지?
3. **환불 권한** — 환불 처리를 운영자가 직접 vs 시스템관리자 승인 필요?
4. **강의 승인 워크플로우** — 강사가 등록 → 운영자 승인 흐름 도입할지?
5. **상담 / 1:1 문의** — 학생의 1:1문의를 어느 메뉴에서 응대할지?
