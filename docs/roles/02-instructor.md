# 강사 (Instructor) — 메뉴 명세 (DRAFT v0.1)

> **Role**: `INSTRUCTOR` (신규)
> **앱**: 별도 앱(`instructor-web`) 신설 또는 `admin-web` 내 강사 모드 분기 — **TBD**
> **현행 구현**: 없음

## 역할 정의

학원 소속 강사. 자기가 담당하는 강의의 콘텐츠·수강생 진도·문제 출제·강의 통계를 관리.
학원 전체 회원/주문/정산에는 접근 불가.

## 메뉴 트리

### 🏠 대시보드
| 메뉴 | 경로 | 설명 | 상태 |
|------|------|------|------|
| 강사 대시보드 | `/dashboard` | 내 강의 요약·신규 수강생·최근 질문 | 신규 |

| 메뉴 | 경로 | 설명 | 상태 |

## 검토 필요 (사용자 의견 요청)

1. **앱 분리 vs 통합** — 강사용 별도 웹 (`instructor-web`) 만들지, `admin-web` 안에서 role 별 메뉴 토글로 갈지?
2. **출제 권한** — 강사가 직접 출제하나, 아니면 운영자가 출제하고 강사는 채점만?
3. **수강생 개인정보** — 강사가 어디까지 볼 수 있는지 (이름·전화·이메일?)
4. **정산** — 강사 본인의 정산 내역 조회 권한 여부 (운영자 영역과 분리 필요)
5. **공지** — 강사가 자기 수강생에게 공지를 직접 보낼 수 있는지?

## 백엔드 매핑 (제안)

- 신규 경로: `/api/instructor/**` → `hasRole("INSTRUCTOR")`
- 데이터 격리: 모든 쿼리에 `WHERE teacher_id = #{currentUserId}` 강제
- `JwtTokenProvider` 에 `INSTRUCTOR` role 추가
