# 공개 영역 (Public) — 메뉴 명세 (DRAFT v0.2)

> **대상**: 모든 방문자 (비로그인 포함)
> **앱**: `user-web` (https://academy.unmong.com)
> **현행 구현**: 부분 (로그인 후만 화면 노출 — 공개 영역 확장 필요)

## 영역 정의

학원 마케팅·정보 제공·신규 회원 유입 채널. **로그인 없이 접근 가능**한 표준 학원 사이트의 골격. 결제·내강의실 등 개인 활동은 [01-student.md](01-student.md) 참조.

## 라우팅 규칙

### 비로그인 접근 가능 (게이트 없음)
`/about`, `/faculty`, `/courses`, `/books`, `/info/**`, `/membership`, `/support/notice`, `/support/faq`

### 로그인 필요 (게이트 적용)
`/support/inquiry` (1:1 문의 등록·조회 — 응답 메일 추적 위해 회원 식별 필수)
→ 비로그인 시 `/login?next=/support/inquiry`

### Role 분기 redirect
`/membership` 클릭:
- 비로그인 → 회원가입 안내 화면 노출
- 로그인 → `/mypage/profile` 자동 이동

## 검토 필요 (사용자 의견 요청)

1. **학습정보 콘텐츠 등록 주체** — 운영자만 / 강사도 등록?
2. **합격 후기 등록 흐름** — 더미 데이터로 시작. 향후 실데이터 도입 시 학생 → 운영자 검수 → 게시?
3. **고객센터 카테고리 표준** — 수강·결제·기술·환불·기타? AI 라우팅 모델의 분류 기준
4. **공개 영역 SEO** — 우선 예외 처리 (Sprint 후순위)

## 백엔드 매핑 (제안)

- 신규 경로: `/api/public/**` (인증 없이 접근 가능, GET 위주)
- 콘텐츠 관리: 운영자 영역 (`/api/operator/contents/**`) 에서 등록·수정 → 공개 영역에서 조회
- 1:1 문의: `/api/user/inquiries/**` (현 USER role 필요)
- AI 라우팅: 별도 워커 (Spring `@Async` 또는 외부 큐) — Sprint 후순위
