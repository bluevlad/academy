## 권한 구현 메모 (개발자용)

- 백엔드: `Role.java` enum 확장 → `JwtTokenProvider` claim 에 role 직접 직렬화
- 백엔드: `SecurityConfig` 의 `/api/admin/**` → `/api/operator/**`, `/api/sysadmin/**` 분리 검토
- 프런트: `AdminShell` 메뉴 → role 별 동적 렌더링 (현재 하드코딩)
- 프런트: `RequireAuth` → `RequireRole(role)` HOC 추가
