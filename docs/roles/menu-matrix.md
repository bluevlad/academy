## 권한 구현 메모 (개발자용)

- 백엔드: `Role.java` enum 확장 → `JwtTokenProvider` claim 에 role 직접 직렬화
- 백엔드: `/api/public/**` 신설 (permitAll 확대) — 공개 콘텐츠용
- 백엔드: `/api/admin/**` → `/api/operator/**`, `/api/sysadmin/**` 분리 검토
- 프론트: `AdminShell`·`UserShell` 메뉴 → role 별 동적 렌더링
- 프론트: 메뉴 라벨 DB 조회 (커스터마이징 지원)
- 프론트: `/classroom` 라우터에 role 기반 redirect hoc
