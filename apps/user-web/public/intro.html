Academy

Integrated Academy System (Admin + User Monorepo)

공무원 학원 통합 운영 시스템. 수강생 포털(User)과 관리자 콘솔(Admin)을 단일 Spring Boot 백엔드로 통합한 monorepo 아키텍처. URL prefix(/api/admin, /api/user, /api/shared)로 경계를 강제합니다.
